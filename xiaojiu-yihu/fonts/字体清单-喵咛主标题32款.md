## 四、使用注意（实测）

1. **变量字体默认字重偏细**：以下文件是可变字体，且默认实例不是 Regular——

| 文件 | 默认 wght | 可用上限 |
|---|---|---|
| `NotoSerifSC[wght].ttf` | 200 | 900 |
| `NotoSansSC[wght].ttf` | 100 | 900 |
| `CormorantGaramond[wght].ttf` | 300 | 700 |
| `SpaceGrotesk[wght].ttf` | 300 | 700 |
| `Rubik[wght].ttf` | 300 | 900 |
| `NotoSansJP[wght].ttf` | 100 | 900 |
| `NotoSerifJP[wght].ttf` | 200 | 900 |
| `NotoSansKR[wght].ttf` | 100 | 900 |
| `NotoSerifKR[wght].ttf` | 200 | 900 |

   FFmpeg `drawtext`、PIL `ImageFont.truetype` 都只会取默认实例，直接用会得到偏细的字形。需要标题粗重效果时，用 `fonttools varLib.instancer` 生成固定字重（示例见第五节）。

2. **文件名含方括号**：`NotoSerifSC[wght].ttf` 这类名字在 shell 里会被当作通配符，脚本中请加引号或 `set -f`。
3. **喵咛狗爬黑分两个字面**：上游只提供 `.ttc` 字体集合，本目录已拆成 `MiorningGoupaHei-Regular.ttf`（65535 字形，覆盖常用中文）与 `MiorningGoupaHeiExtra-Regular.ttf`（5533 字形，仅 CJK 扩展 B 生僻字，不含常用字）。做标题用前者，生僻人名再补后者。
4. **日/韩字体不含简体专用字**：Noto Sans JP、Klee One、Zen Maru Gothic 等日文字体没有「汉」「题」「设」「计」这类简体专用字形，排简体中文会出现豆腐块；同理韩文字体只覆盖韩文汉字集。选字体前先用预览图确认字形覆盖。
5. **本目录既有字体未改动**：`NotoSansSC-500/900.woff`、`ZCOOLQingKeHuangYou-Regular.ttf`、`MaShanZheng-Regular.woff2` 等原文件保持原样。

## 五、生成固定字重（示例）

```bash
# 例：把 Noto Serif SC 固定到 700（Bold），输出可直接给 ffmpeg/PIL 用
fonttools varLib.instancer "NotoSerifSC[wght].ttf" wght=700 -o NotoSerifSC-700.ttf
```
