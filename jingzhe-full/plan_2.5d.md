## 0. 定了的

- 风格：**国潮剪纸 / 层叠山水，2.5D**。每个场景 6–8 层剪影，层间有雾，镜头推、拉、横移出视差。
- 层的图：**全部程序生成**（SVG 路径或着色器画剪影），不准备素材，画面只由时间决定（determinism）。
- **贯穿全片的是仙女**（VRM 模型），**火种整个去掉**。她身上的光是全片唯一的暖光：山火的红、雷的白都是她引出来的，从她开始、在她结束。
- 顺序：先做**尾声 bar97–123 样片**，用户点头再往前改；整首统一成剪纸版（前奏 bar1–16 的 Blender 版也不要了）。
- 规矩照旧：不按歌词画画面，按拍点做；不抖不闪（雷只占画面一小条、0.9 秒暗完）；不为卡点减速；相邻转场不同类；换镜头要看到新东西；东西画细、认得出，不要水墨写意；歌词右下角一行小字；片头片尾 mv-line-art 线条字（ZCOOLKuaiLe）；最后一帧接第一帧；转得不晕（≤ 60°/s）。
- 她出现的比例：几乎每镜都在（用户 2026-11-19 定）。
- （用户 2026-11-19 定，盖过第 2 节）**不用赛璐璐画风**，保留模型自己的 MToon 质感，只加暖金光和飘带；**等比缩成小精灵大小**（约一掌高，十几厘米），场景尺度按她来；**全身和猫尾巴都能任意动**：尾巴 10 节骨（`J_Opt_C_CatTail1–8`）也进姿势库，按时间算，不靠 springBone。
- 模型：`assets/fairy.vrm`（VRM 1.0，作者是用户本人；meta 写的禁止再分发，`assets/` 不进 git）。three-vrm 3.3.3 在 `lib/`。

## 1. 剪纸卡（画面语言）

- 层（远到近约 7 层）：天、远山、中山、近山、林、前景（枝、草、剪纸花窗）、粒子。每层是带透明的面片，按 z 摆开，透视镜头拍。
- 剪纸感：剪影边缘有锯齿或镂空纹样（云纹、回纹、花瓣孔）；每层边缘 1–2 像素亮边（背光）；纸纹、纤维；背面投一道柔影在下一层上。
- 配色（每段一套，同时最多三色加金）：冬 靛青 / 月白；山火 墨黑 / 朱红 / 金；春 青绿 / 桃粉 / 金；尾声雷 深蓝紫 / 雷白 / 金。暖金只出现在她身上和她引出来的光里。
- 光：只有她、雷、开花发光（加法混合 + bloom）。层本身不打复杂光，按深度变暗变冷再叠雾。
- 后期（先做，最出质感）：bloom、细颗粒、暗角、轻微色差、统一调色。

## 2. 仙女

- 模型：`~/Projects/personal/建模/仙女/仙女.vrm`（用户给的，在项目外）。**开工第一步**：
  1. 读 VRM meta：作者、能否商用、能否改、使用范围；不允许就停下问用户。
  2. 看规格：面数、材质、贴图大小、VRM 0.x 还是 1.0、骨骼、有哪些表情。太重就做简化版。
  3. 跟用户确认后复制进项目 `assets/`（项目外的文件按规矩先问）。
  4. three-vrm 放进 `lib/`，版本对上现有 three.js（GitHub 文件走 API 下载；测试用 Python 的 playwright，Node 的没装）。
- 定位：「惊蛰」的春神。冰里沉睡 → 醒来 → 穿过山火、水下、雷、宇宙 → 落回湖面 → 春天一路飞、所到之处开花 → 引雷开春 → 全片的光收回她身上，回冰里睡下，最后一帧接第一帧。
- 怎么放进 2.5D：three-vrm 实时渲染，当成剪纸层里的一层合成（不预渲染，镜头、视差、转场能连上）。
  - 换掉 MToon，用自己的赛璐璐着色：2–3 阶明暗，颜色取当段配色；背光亮边和剪纸层同色；背面外扩描边；叠纸纹、颗粒；投柔影到身后那层。
  - 四种画法做成开关：**赛璐璐 / 纯色剪影 / 发光轮廓线 / 水面倒影**。远景用剪影或简化网格。
  - 长焦拍（小 fov），透视弱、像平面。
- 她自己发光：身体边缘一道暖金色的光，**飘带最亮**。冰下、沉睡时不发光，画面里就没有暖色。
- 飘带（新贯穿元素）：程序生成几条长飘带挂在肩上，发光金边；飞起来拖得很长，尾巴掉下光屑（原来火种的拖尾、火星改挂在这里）。飘带扫过镜头 = F，卷成螺旋 = E/G。
- 签名螺旋：改成她飘带绕成的螺旋，从上往下看顺时针（和原来同向）。
- 动作：姿势库约 20 个（睡、蜷、睁眼、浮起、伸手、托光、回身、旋转、俯冲、展臂引雷、指、拥抱、坠落、仰望……），按时间插值（`{t, pose, 混合}`，用 `JZ.path`）。姿势库单独一个文件。
  - 头发、裙子：不用 springBone 的逐帧模拟（跳着渲染结果不同，破坏 determinism），改成按时间算的正弦摆动；以后要真模拟就每帧从镜头开头按固定步长重算。
  - 脸：VRM 表情（眨眼、睁眼、微笑），睁眼放在大时刻上。
- 她一直在，怎么不腻（新规矩）：每次换镜头至少换一样
  - 大小：远景剪影（约 5%）/ 全身 / 半身 / 手或眼特写，同一大小不连用两镜；
  - 姿势：相邻镜头不重复；
  - 她和光的关系：托着、追着、被带着、放走、收回；
  - 画法：赛璐璐 / 剪影 / 轮廓线 / 倒影；
  - 飘带：长短、颜色跟段落变，有时只露飘带不露人。

## 6. 转场在 2.5D 里怎么做（转场表 74 个的类、顺序照旧，只换做法；写「火种」的按第 3 节换成她）

| 类 | 做法 |
|---|---|
| A 一镜到底 | 沿 z 往里推或横移，穿过一层层山 |
| B 穿过实物 | 前景剪影上镂空一个洞（花窗、山口、树洞），从洞里穿过 |
| C 穿过水面 | 水面那层是一条横线，从画面上扫过，线下换成水下的层 |
| D 尺度推进 | 推进她的手心或一朵剪纸花，里面是下一个场景 |
| E 形状接形状 | 同形剪影（圆月、湖、飘带螺旋）叠化 |
| F 前景划过 | 近景剪影或她的飘带横扫画面，后面换了 |
| G 粒子重组 | 花瓣、萤火、光屑散开，落成下一个形状 |
| H 光源接光源 | 她的光、雷、月亮互相接 |
| L 冲 | 小节头往 z 猛冲，几层山一下扑过来 |

卡点：底鼓 她身上的光鼓一下 + 很轻的色差；军鼓 近景层轻轻「呼吸」（缩放 ±1%）。不抖整个画面。

## 7. 技术结构（新文件）

- `jz_paper.js`：剪纸层生成（山脊线噪声或 `landH()` 剖面，树、花、云纹 SVG 路径，按 z 摆面片）。

- `jz_post.js`：bloom、颗粒、暗角、色差、调色。
- `scene.js`：按 cues.json 镜头名分派到新画法。`jz_core.js` 沿用 `JZ.path`、`JZ.blend`、`JZ.present`。
