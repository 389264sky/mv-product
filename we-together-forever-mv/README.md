# 《我会等》MV（可预览、可渲染的工程）

一支用网页画出来的 MV：`index.html` 逐帧画画面，`scripts/render.py` 把它渲成视频。
照片是占位图，画面和文档里的人名写成 `XX`、日期写成 `20XX.XX.XX`、地点写成 `地点1`、`地点2`…，换成你自己的就能用。

> **声明：本工程仅供个人学习和非商业使用，禁止任何商业用途**（包括但不限于出售、收费代做、用于广告或商业推广）。详见文末「署名与许可」。

## 准备

要装三样东西，都装好才能预览和渲染：

1. **Python 3.10 以上**（[python.org](https://www.python.org/downloads/)）。
2. **Python 依赖**（playwright、pillow、numpy，版本在 `requirements.txt`）和渲染用的浏览器。在工程目录里跑：
   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   ```
3. **ffmpeg**，装好后 `ffmpeg -version` 能打印版本号才算成。macOS：`brew install ffmpeg`；Windows：`winget install ffmpeg`；Linux：`sudo apt install ffmpeg`。

只想预览不渲染的话，有第 1 项就够。渲染要用显卡画 3D 人物，没有显卡的机器（比如云服务器）会很慢。

作者跑通的环境：macOS（Apple 芯片）、Python 3.13、playwright 1.64、pillow 13.0、numpy（见 `requirements.txt`）、ffmpeg 9.0。Windows 和 Linux 没有实测。

## 预览（带声音）

```
python scripts/preview.py .
```

打开打印出来的网址：空格播放，←→ 跳小节，D 显示节拍信息。

## 渲染

> **本仓库只提供草稿**：`out/mv_草稿.mp4`（960×540、30 帧，约 44 MB），先看效果用。1080P 正片太大（约 600 MB），仓库就不放了，你们直接用下面第二条命令渲出来就行，出来是 `out/mv.mp4`。正片带 2 倍超采样和运动模糊，比草稿慢得多：作者的 Mac（M5）上估计二十分钟上下，机器不同差别会很大。

```
python scripts/render.py . video --draft     # 草稿 960×540、30 帧，约一分钟 → out/mv_草稿.mp4
python scripts/render.py . video             # 成片 1920×1080、60 帧 → out/mv.mp4
python scripts/render.py . shots             # 每个镜头一张 → out/stills/
```

其他出图方式见 `scripts/render.py` 开头的说明。

## 换照片（按时间线排）

照片按时间线排，整支片子照这个顺序展示：

- 一段时间（一次旅行、一年、一件事）一个文件夹 `照片/<组名>/`，文件夹里的照片按先后起名 `00.jpg`、`01.jpg`…（按文件名里的数字排）。
- 文件夹之间的先后在 `photos.py` 的 `GROUPS`：从上到下就是从最早到最近。加一段时间 = 新建一个文件夹，再把组名插到 `GROUPS` 里它该在的位置。
- 改完跑 `python photos.py`，生成 `photos.js`。每张照片的键是「组名 + 两位序号」（如 `wed03`）；`PHOTOS.all` 是全部照片按时间从早到晚的清单，片尾的照片路、星图、拼心这些汇总镜头直接按它排。
- 其余镜头放哪几张，在 `cues.json` 每个镜头的 `params.ph` 里按键点名；换了组名或删了照片，要把这里用到的键一起改。
- 每个镜头在什么时刻出现：`cues.json` 的 `shots` 里的 `at`。

## 改旁白（日期卡、小字、告白）

人名、日期、地点、告白都在这里改。画面左上角的三行字：日期（大字）、小字（日期下面一行）、告白（再下面一句）。

- `旁白.txt` 是给人看的清单：【1】–【32】按出现顺序列出每条的日期、小字、告白和大约出现的秒数。程序不读它，只改它画面不会变。
- 真正生效的是 `scene.js` 里的 `CARDS`（搜 `const CARDS`）：一行一条，顺序和 `旁白.txt` 的【1】–【32】一一对应（写着 `end: true` 的行只是把前面的字收掉，不算条数）。照着 `旁白.txt` 找到第几条，改那一行引号里的字：
  - `date`：日期，比如 `'2020.05.01'`、`'2020 — 2022'`。和上一条一样时不会重新落一次。
  - `what`：小字。
  - `say`：告白。没写 `say` 的那条沿用上一句。尽量不超过 21 个字，太长会伸到照片的位置。
  - `at`：这一条什么时候出来，一般不用动。`bar2` 是第 2 小节，`line9` 是第 9 句歌词开唱，`line7@花` 是第 7 句唱到「花」字。
- 不在 `CARDS` 里的字，在 `scene.js` 里直接搜：片头片尾的 `写给 XX`、`XX · 20XX—余生`，结婚证上的 `XX & XX`、`XX`、`20XX.XX.XX`、`20XX年XX月XX日`。
- 只改引号里面的字，引号、逗号、花括号别删。改完保存，刷新预览页面就能看到；看着对了再渲染，顺手把 `旁白.txt` 也改成一样的。

## 片头（发布用，可关掉）

正片前面有一段约 20 秒的片头：黑底，键盘一个字一个字打出来，配键盘声，不放歌也不放正片画面；打完暗下去，0 秒才切进正片。一共三屏，每屏打完敲一下删除清屏：

1. 你也想表白吗？ / 从校服，到婚纱的她 / 或者，有更美好际遇的她
2. 制作不易，给个关注吧 🥰
3. 下面，正片开始（下面两行小字备注：MV需要补上你们美美的照片和旁白哟！/ 项目已开源，地址见评论区；第一行打完会波浪式轻轻跳动，“开源”“评论区”用强调色）

发布用的标题、正文、话题和封面见 `发布文案.md`。片头的设置都在 `cues.json` 的 `intro` 里：

- **不要片头**：见下面「去掉片头」。
- **改字**：`pages` 一屏一组，组里一行一条，【】里的字用强调色。一行也可以写成 `{"text": "…", "size": 50, "fill": "#c8c8d2", "gap": 0.07}`，单独换字号、颜色、打字快慢，加 `"fx": "wave"` 打完会波浪式跳动，第三屏的小字备注就是这么写的；空格会照样打出来。句末的 🥰 是表情，打出来时会弹一下、往上飘几颗小心，并响一声 `sfx/emoji.wav`（写别的表情也一样）；表情靠系统的表情字体显示：Mac、Windows 上是彩色的，有的 Linux 没装表情字体会显示成方框，可以删掉或换一个。加一屏、删一屏、改一行都行，片头长度跟着字数自动变。
- **快慢**：`gap` 每个字隔几秒，`pause` 换行前停多久，`hold` 一屏打完停多久再清屏，`end` 最后一屏打完停多久，`out` 最后暗下去用几秒，`start` 开头光标先闪多久。
- **字体、字号、光标**：`font`（`fonts/fonts.json` 里的名字）、`size`，光标颜色 `caret`（现在是橙色）。
- **键盘声**：`sfx/` 里的 `key1`–`key5`（按键）、`enter`（回车）、`del`（清屏）、`emoji`（表情冒出来），是用程序合成的，没有版权问题。想换成自己录的，存成同名的 48 kHz、单声道、16 位 wav 就行；`volume` 是音量。
- **时间**：片头在时间轴的负数那一段，正片从 0 秒起；`cues.json`、`旁白.txt` 里写的秒数和 `bar`、`line` 都是正片的，不算片头。看片头的静帧：`python scripts/render.py . stills -12.133`。

### 去掉片头

片头是发布这支视频时加的，拿这个工程做你们自己的 MV，一般用不上。去掉只要改一处：

1. 打开 `cues.json`，搜 `"intro"`，把它下面一行的 `"on": true,` 改成 `"on": false,`（后面的逗号留着）。
2. 保存，刷新预览页面：进度条直接从正片 0 秒开始，没有黑底打字和键盘声。
3. 照常渲染 `python scripts/render.py . video`，出来的视频就从正片开始。

以后想要回来，把 `false` 改回 `true`，片头的字和设置都还在。

- **只是这一次不要**：不改文件，渲染时加 `--from 0`：`python scripts/render.py . video --from 0`。
- **确定不要了**：也可以把 `cues.json` 里整段 `"intro": { … },` 删掉，效果一样；只给片头用的 `sfx/` 文件夹、`发布文案.md`、`out/发布封面.jpg`、`out/发布封面_竖版.jpg` 也能删，不删也不影响。

## 注意

- `out/blender/` 里是 3 个镜头（hug、homeRain、homeRain2）用 Blender 渲好的人物帧，成片要用，清 `out/` 时别删。
- home1、home2 两个镜头没带 Blender 帧（原帧里有真照片），成片里用网页的 3D 人物代替，光影比其他 Blender 镜头粗。要重渲需要 Blender、VRM 插件和人物模型（`blender/build.py`），模型不在这个工程里。
